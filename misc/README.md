## Collection of non-runtime functions

There are things of little importance and things of critical importance in this
folder. 

Important things include:

* build_standalone
    Tools for building stand alone release, DB etc.
* collections_comparison
    Misc. utils for managing collections
* genra_ni
    Pre-2020 web app. code for reference, Python 2
* tickets
    Ticket specific scripts / notebooks.  Some of these are "proofs", some
    *need to be moved*, e.g. pesticide, pfas FP support.
